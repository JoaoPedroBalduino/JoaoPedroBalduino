## Experiência — Engenharia de Dados na SSP-PI

**Dicionário de dados de bancos operacionais**
Documentei do zero dois bancos PostgreSQL (128 tabelas), com tipos, chaves, regras de negócio e classificação de dados sensíveis (LGPD). Criei também uma view SQL de veículos roubados e furtados não recuperados, que alimenta um sistema de inteligência policial.

**Otimização de pipeline Airflow → Elasticsearch**
Corrigi falhas por esgotamento de conexões causadas pelo padrão N+1. Com consultas em lote e lookup em memória, as queries por lote caíram de **3.000 para 3**. Também integrei uma nova fonte ao índice de busca e reindexei os documentos via upsert, sem indisponibilidade.

**Painel gerencial para a Polícia Civil** *(em andamento)*
Estudo de viabilidade de mais de 30 indicadores, EDA em notebooks e camada de staging em SQL sobre uma base de milhões de registros. O painel é em Streamlit, com autenticação.

> Projetos institucionais: o código e os dados são confidenciais e não estão públicos.
